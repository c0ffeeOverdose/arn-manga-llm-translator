      Translation text

      px
      Text can shrink to this size to fit a bubble. Lower values fit more text but can be harder to read.
      ×
      1× matches the original text size. Increase for larger text. Long translations still shrink to fit.
      ×font
      Adds an edge around letters so they stand out over artwork. Set to 0 to turn it off.
      Auto chooses text and outline colors for contrast with the background.

      Characters

      Edit names, appearance and notes to guide future translations. Changes save automatically for each story. Re-translate a page to apply them there.
      Characters appear here after you translate a page.

      Translation settings

      Detection
      Lower values detect more text, but may also select artwork.
      Lower values detect more panels, but may mistake other shapes for panels.
      Defaults: text 0.25, sound effects 0.20, panels 0.50. Lower values may include artwork.
      px
      Context
      Number of recent dialogue entries sent with each request. More history uses more tokens.
      Images
      px
      Larger crops can make small text easier to read and may use more tokens.
      px
      Performance
      Lower this if your provider limits requests. Auto-translate uses parallel requests when dialogue context is off.
      Other translations always send one page per request.
      Saved translations
      Uses a saved result when you translate a page again with the same settings.
