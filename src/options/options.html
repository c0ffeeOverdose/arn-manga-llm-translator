      How the model reads text

      OCR runs wherever detection runs (see above) — on-device needs the models below, cloud needs none.
      Sets the region numbering order for every mode above.
      The model copies each box's original text alongside the translation — richer cross-page context at roughly 2× output tokens. No effect in OCR mode.
      A cheap/fast vision model transcribes each box, then your main model translates text-only — 2 LLM calls per page, using the same images as above. No effect in OCR mode.
      One crop per call — for models that accept a single image (e.g. Cloudflare llama-3.2-11b-vision). Leave off for auto-detect: a rejected batch falls back to per-region on its own and remembers the model.

      Render font

      px
      Floor for shrink-to-fit: smaller fits long text without clipping, but gets hard to read.
      Tall boxes render left-to-right first and rotate only when the text can't fit. Off = rotate tall columns as before.
      ×font
      Edge around the text (0 = off). Helps on busy art; invisible on matching bubbles. Color follows Auto unless overridden below.
      Auto follows the text: dark edge on light text, white edge on dark text.
      Presets download once and work offline.

      Detection
      Lower catches more small text, with more false positives.
