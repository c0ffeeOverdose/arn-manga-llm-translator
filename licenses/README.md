# Third-party license texts

These files are copied unchanged into Chrome and Firefox builds.
The extension's own license is in ../LICENSE; attribution and model terms are in ../NOTICE.

| File | Source |
| --- | --- |
| ONNXRuntime-MIT.txt | https://raw.githubusercontent.com/microsoft/onnxruntime/v1.29.0/LICENSE |
| ONNXRuntime-ThirdPartyNotices.txt | https://raw.githubusercontent.com/microsoft/onnxruntime/v1.29.0/ThirdPartyNotices.txt |
| Apache-2.0.txt | Tesseract.js 5.1.1, node_modules/tesseract.js/LICENSE.md; also used by Tesseract.js-core 5.1.0 |
| Sriracha-OFL.txt | https://raw.githubusercontent.com/google/fonts/main/ofl/sriracha/OFL.txt |

The Sriracha copyright holders match the bundled font's name table.
Downloaded font presets retain the individual licenses in google/fonts.

The build also copies the root LICENSE and NOTICE to licenses/LICENSE.txt and
licenses/NOTICE.txt so the About links open as plain text in the browser.
